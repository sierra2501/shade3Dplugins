# shade3Dplugins

Shade3Dのプラグイン

- addRand.py
  - 選択した頂点に乱数を混ぜる。
- alignAxis.py
  - 軸に合わせて形状を移動します。
- copyPolygonMesh.py
  - ポリゴンメッシュを左右上下前後の一方向に指定回数並べる。
- myColorPicker
  - 単体でも（直接index.htmlを開いても）機能します。
- setBoneJointLimit.py / mirrorBoneJointLimit.py
  - ボーンジョイントの回転角制御をJSON形式で設定／読み込む。
- storeActiveVertex.py / selectVertex.py
  - 選択した頂点を一時保存する。
- sumRom.py
  - 選択した稜線の長さの合計を求める。
